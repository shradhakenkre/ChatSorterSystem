📩 Chat Sorting System

📢 An intelligent Java-based chat classification system that automatically sorts messages into Work, Personal, or Spam categories.

🚀 Powered by Object-Oriented Programming (OOP), Regex Matching, and Sentiment Analysis.

🔥 Features
✔ Smart Message Categorization
✔ OOP Principles Implemented (Abstraction, Encapsulation, Inheritance, Polymorphism)
✔ Robust Regex-based Classification
✔ Sentiment Analysis for Messages
✔ Error Handling for Invalid Inputs

🛠️ Tech Stack
Technology	Purpose
Java	Core Development
Regex Matching	Message Classification
Object-Oriented Programming	Structuring the System
🚀 How It Works
🔹 The system takes a long user message as input.
🔹 It detects keywords to classify the chat.
🔹 It assigns the message to one of the following:

📂 Work Chat (e.g., "meeting", "deadline", "client")

🏡 Personal Chat (e.g., "birthday", "vacation", "weekend")

🚨 Spam Chat (e.g., "win", "lottery", "click here")
🔹 It displays the message category and sentiment analysis.
