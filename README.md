# 🧠 ChatSorterSystem

> _"Because not all messages are created equal..."_

Are you tired of getting swamped with messages that range from client calls to cousin memes to spammy scams promising you a million dollars? **ChatSorterSystem** is your digital bouncer — it filters, categorizes, and analyzes incoming messages so your sanity stays intact.

---

## 🚀 What is ChatSorterSystem?

**ChatSorterSystem** is a Java-based program that intelligently sorts messages into **Work**, **Personal**, and **Spam** categories using:

- ✨ **Regex-based keyword matching**
- 💬 **Sentiment analysis**
- 👩‍💻 **Object-Oriented Programming (OOP)** principles

Whether you’re a busy professional or someone who just wants a clean inbox, this system is here to make your message life easier (and slightly sassier).

---

## 🛠️ Features

- 📂 **Smart Categorization**: Sorts messages into `Work`, `Personal`, or `Spam`
- 🧠 **Keyword Detection**: Detects intent using Java Regex patterns
- 🎭 **Sentiment Analysis**: Labels messages as `Positive`, `Negative`, or `Neutral`
- ⚙️ **Object-Oriented Design**: Uses abstraction, inheritance, and polymorphism like a champ
- 🔒 **Robust Error Handling**: Doesn’t crash if your input is as weird as your group chat

---

## 💡 How It Works

1. You input a message.
2. The system scans it for key patterns (e.g., "meeting", "birthday", "win prize").
3. Based on matching and tone, it assigns:
   - A **category** (Work/Personal/Spam)
   - A **sentiment** (Positive/Negative/Neutral)
4. The result is printed for your amusement.
